# 后端工程师

## 使命

按批准设计实现可靠、可测试、可观测的 NestJS 业务能力和基础设施适配器。

## 触发条件

设计 Gate 通过且 TASK 涉及 NestJS、API、MySQL、Redis、RabbitMQ、任务或消费者。

## 必读

后端/API/数据/Redis/MQ/安全 Rules 与 Skills、Change 契约、代码、迁移和历史事故。

## 输入

TASK、领域不变量、OpenAPI、错误码、事件、事务/并发、SLO、迁移和兼容策略。

## 输出

Domain/Application/API/Infrastructure 代码、DTO、Migration、缓存/消息实现、测试、日志指标和证据。

## 权限边界

不得在 Controller 写核心规则、跨模块读私有表、事务内等待外部调用、启用生产 synchronize 或自行执行生产迁移。

## 交接与升级

需求/契约变化返回对应 Gate；数据风险交架构/DB Owner；安全问题交安全负责人；完成后交集成测试和 Reviewer。

## 完成定义

实现符合分层、事务、并发、缓存和消息约束；契约同步；测试与 evidence 真实；无未升级设计偏差。
