# 发布、灰度与生产验证

## 触发条件

- Change 已通过验证和独立评审，准备进入 `ready_for_release` 或 `released`。
- 需要执行预发布演练、灰度、生产冒烟、回滚或发布后观察。
- 数据库、消费者、配置或客户端发布存在严格顺序。

## 不适用场景

- 仅实现或测试代码。
- 发布 Gate 未批准时执行任何生产变更。
- 把“生成发布计划”误认为已经完成部署。

## 前置 Gate

- 验证 Gate、安全 Gate 和独立 Reviewer 结论满足发布政策。
- UAT Gate 与 Operations Gate 已通过或有合法 not-required 决策。
- `release-plan.md`、`rollback-plan.md`、必要 migration plan 完整并获批准。
- 生产执行还必须有用户明确授权、操作者身份和环境权限；缺一只做 dry-run。

## 必读上下文

1. `rules/12-Git与CI规范.md`、`rules/13-发布回滚与可观测性.md`。
2. `wiki/11-部署拓扑.md`、`wiki/12-可观测性模型.md`。
3. Change 状态、审批、制品、测试、安全、发布、回滚和迁移文件。
4. API/消息兼容矩阵、功能开关、配置差异和历史发布事故/Runbook。

## 输入

- 不可变制品、提交 SHA、镜像 digest、uni-app 包版本和发布目标环境。
- 配置/Secret 引用、数据库和消息拓扑变化、灰度策略与值班人。
- 基线指标、发布阈值、回滚触发器和业务验收人。

## 执行步骤

1. 核对 Change、审批、目标环境和操作者权限，确认当前任务允许 dry-run 还是实际执行。
2. 校验制品 SHA/digest、依赖锁、签名、镜像来源和前端版本号，不在部署时重新构建漂移制品。
3. 比较环境配置，仅检查 Secret 引用和存在性，不输出真实值。
4. 确认发布顺序：兼容消费者/worker、NestJS API、数据库迁移、uni-app 客户端、功能开关。
5. 在预发布环境执行 migration、应用启动、健康检查、API/MQ/缓存和关键 E2E 冒烟。
6. 确认日志、trace、业务指标、队列积压、DLQ、数据库和 Redis 告警已经生效。
7. 执行 `operational-readiness`，核对 SLO、容量、Runbook、值班、备份恢复与 Incident 计划。
7. 实际执行前记录开始时间、版本、Owner、基线指标和回滚决策人。
8. 按批准批次灰度，每批观察错误率、P95/P99、业务成功率、锁等待、缓存和队列指标。
9. 指标超过阈值立即停止扩容；按计划关闭功能开关、回滚应用或执行前向修复。
10. 发布完成后执行生产只读/最小副作用冒烟，禁止随意创建无法清理的业务数据。
11. 在规定观察窗持续记录指标、告警和用户反馈，确认无延迟故障。
12. 更新状态、发布证据、实际偏差、回滚可用性和后续事项。

## 技术约束

- 数据库采用 expand-migrate-contract，应用回滚不得依赖已删除的旧列或契约。
- RabbitMQ 新旧消费者在滚动期间必须兼容；删除 queue/binding 需确认无生产者和积压。
- Redis Key/schema 变化使用版本或双读策略，不能在滚动期间让新旧实例互相污染。
- uni-app 客户端不可强制即时更新，服务端必须遵守批准的旧版本兼容窗口。
- 健康检查区分 liveness/readiness，不因依赖短暂波动造成无限重启。
- 回滚命令、权限和制品必须在发布前验证，不能等事故发生再设计。

## 产物

- 完整 release/rollback/migration 执行清单及审批记录。
- UAT、运营就绪、SLO、灾备和 Incident 响应证据。
- 制品、SHA/digest、环境、命令或流水线链接、操作者和时间记录。
- 灰度批次、监控截图/数据、冒烟结果、异常和回滚结果。
- 实际发布状态、残余风险和观察窗结论。

## 验证与证据

- 每一步记录实际结果与退出状态；未执行项标记 `not-run`。
- 版本、数据库 schema、配置版本、队列/消费者和前端包均可核验。
- 冒烟覆盖关键读写、权限、缓存和异步最终结果，而非只有进程存活。
- 回滚或功能开关路径至少 dry-run/演练通过，证据绑定当前制品。

## 停止与升级条件

- 缺少生产授权、审批、值班人、回滚决策人或可用回滚制品。
- 制品与评审 SHA 不一致，配置差异未知或迁移未演练。
- 错误率、延迟、业务失败、数据库锁、缓存故障或队列积压达到阈值。
- 监控不可用、证据无法记录或实际环境与计划不符。

## 禁止事项

- 不从本 Skill 推断生产权限，不绕过发布 Gate。
- 不输出或保存 Secret，不临时手改未审查生产代码/配置。
- 不把计划、dry-run 或预发布结果写成生产成功。
- 不在指标异常时继续扩大灰度以“观察是否恢复”。

## 完成定义

批准范围内发布按顺序执行；制品与环境可核验；灰度、冒烟、监控和观察窗满足阈值；异常已停止或回滚；证据真实完整；状态准确反映 `not-run`、失败或成功。
