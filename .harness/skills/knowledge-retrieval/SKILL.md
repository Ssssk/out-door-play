# 工程知识检索

## 触发条件

- 开始需求分析、影响分析、技术设计、编码、排障、测试、评审或发布。
- 遇到错误、异常指标、跨端差异、数据不一致、缓存或消息可靠性问题。
- 准备做技术选型、架构决策、依赖升级或执行高风险 Runbook。

## 不适用场景

- 用历史记录替代当前代码、契约、监控和官方资料核验。
- 未经验证直接复制过期代码片段、SQL 或生产命令。
- 将聊天记忆当作仓库持久知识。

## 前置 Gate

- 不要求特定 Change Gate，但必须知道当前目标、模块或症状中的至少一项。
- 读取知识是只读操作；采用会扩大范围或产生外部副作用的方案仍需对应审批。
- 涉及生产事故时，检索不得延误已批准的止损动作。

## 必读上下文

1. `.harness/manifest.yaml`、`rules/14-AI技能与知识治理规范.md`。
2. `knowledge/README.md`、`knowledge/index.yaml`。
3. 当前 Change 的请求、需求、影响、设计或故障现象。
4. 与模块相关的 Wiki 当前事实。

## 输入

- Change ID、阶段、工作类型和目标。
- 领域、模块、页面、API、表、Redis Key、事件、错误码或依赖名称。
- 症状、日志关键词、异常类型、平台和版本。

## 执行步骤

1. 从当前工作提取检索词：中文业务词、英文模块名、错误码、技术栈、资源名和症状。
2. 先读 `knowledge/index.yaml`，按 type、scope、stack、tags、status 定位候选记录。
3. 使用 `rg -i` 搜索 `knowledge/`、`wiki/` 和 `changes/`，同时覆盖中英文同义词。
4. 对每个候选读取完整记录，核对 ID、状态、适用边界、版本和 `last_verified`。
5. 核对来源类型和证据等级：个人经验、外部文章、结构校验、项目测试和生产观测不得视为同等证据。
6. 将当前环境与记录环境比较：框架/数据库版本、模块、流量、目标端和故障条件。
7. 按“直接适用、需验证后适用、仅供参考、明确不适用”分类。
8. 对关键结论回查记录中的证据、关联 Change、代码和当前 Wiki，避免循环引用。
9. 若涉及更新频繁的依赖或安全问题，补充官方文档/公告核验，不以旧记录为唯一依据。
10. 在当前 Change 的 `07-knowledge.md` 记录查询词、候选知识 ID、判断和采用方式。
11. 未检索到结果时记录“无匹配”及查询范围，继续基于当前事实工作。

## 技术约束

- `wiki/` 优先回答当前系统是什么；`knowledge/` 回答经验如何复用；`changes/` 回答历史为何改变。
- `verified` 仍需核对适用边界；`draft` 不可作为唯一决策依据。
- `inbox/draft` 只能提供假设、测试设计和风险提示，不得直接成为 Rules 或发布依据。
- `deprecated` 仅用于理解历史；`rejected` 用于避免重复失败，不得当推荐方案。
- 时间敏感知识在超出复核周期或依赖升级后必须重新验证。
- 搜索至少覆盖领域词、技术词和症状词三类，不能只搜用户原句。
- 引用知识使用稳定 ID 和相对路径，不复制整篇内容到 Change。

## 产物

- 当前 Change `07-knowledge.md` 中的检索记录。
- 候选知识的适用性分类、采用/不采用理由和待验证项。
- 设计、任务、测试或排障步骤中对知识 ID 的引用。
- 发现的过期、冲突或缺失知识候选。

## 验证与证据

- 查询词和目录范围可复现，记录实际使用的命令或等价检索方式。
- 每个采用记录的状态、边界、last_verified 和证据均已核对。
- 知识结论与当前代码/Wiki/契约没有未解释冲突。
- 若无匹配，确认不是因为只使用单一语言、错误模块名或漏查 archive。

## 停止与升级条件

- 找到多个互相冲突的 verified 记录且无法通过当前事实判定。
- 知识建议涉及生产写入、数据删除、Secret 或未经批准的外部操作。
- 记录已明显过期，但采用它会影响架构、安全、资金或数据正确性。
- 当前事实与 Wiki 大范围冲突，需要先建立修正文档的 Change。

## 禁止事项

- 不因历史方案曾成功就跳过当前测试和 Gate。
- 不把搜索不到结果表述为“从未发生过”。
- 不秘密采用没有来源、没有边界或包含敏感信息的聊天片段。
- 不自动执行 Runbook 中的生产命令。

## 完成定义

检索范围和关键词可复现；候选记录均完成状态与边界判断；采用项有知识 ID 并进入当前方案/测试；冲突和过期项已升级；未找到结果也有明确记录。
