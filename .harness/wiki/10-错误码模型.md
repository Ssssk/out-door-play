# 错误码模型

错误码格式：`<DOMAIN>_<REASON>`，稳定、全大写、下划线分隔。例如：

| 错误码 | HTTP | 含义 | 客户端建议 |
|---|---:|---|---|
| `COMMON_VALIDATION_FAILED` | 422 | 输入校验失败 | 标记字段 |
| `AUTH_UNAUTHENTICATED` | 401 | 未认证或凭证失效 | 刷新或登录 |
| `AUTH_FORBIDDEN` | 403 | 权限不足 | 展示无权限 |
| `RESOURCE_NOT_FOUND` | 404 | 资源不存在或不可见 | 返回上页 |
| `COMMON_CONFLICT` | 409 | 并发或状态冲突 | 刷新后重试 |
| `COMMON_RATE_LIMITED` | 429 | 请求过频 | 按提示等待 |
| `COMMON_INTERNAL_ERROR` | 500 | 未分类服务端错误 | 记录 requestId |

业务模块维护自己的错误码表。禁止客户端基于中文 message 判断业务分支。
