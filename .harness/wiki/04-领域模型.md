# 领域模型

以下是从当前 Prisma schema 与 PRD 提取的现状，不代表所有业务规则已经批准。

| 限界上下文 | 核心聚合 | 主要责任 |
|---|---|---|
| Discovery | Discovery, Ranking, City | 自驾路线/钓点发现、城市和榜单 |
| Fuel | FuelPrice, FuelStation | 城市油价和附近站点 |
| User | User, Favorite | 用户资料、里程/打卡和收藏 |
| Content | Feed | 用户内容、举报数与审核状态 |
| Reporting | DailyMetric, ReportTask | 分析指标和报表任务 |
| Administration | AuditLog | 运营变更审计 |
| Identity | 尚未实现 | 用户/管理员登录、会话和授权 |

## 建模规则

- 聚合边界围绕一致性需求，不围绕数据库表数量。
- 领域对象使用业务 ID；跨上下文只引用 ID 和稳定快照。
- 值对象不可变并在创建时保证自身有效。
- 领域事件只表达已发生事实，事件名称和载荷不暴露 ORM record。
- 状态机必须枚举允许转换，并测试非法转换。
