# 接口协议

## 基线

- 当前 JSON API 根路径 `/v1`；本地 HTTP，生产 HTTPS/Ingress 尚未设计。
- `Content-Type: application/json; charset=utf-8`。
- 服务端读取或生成 `X-Request-Id`，响应 envelope 为 `{ code, message, data, traceId }`。
- 时间为 ISO 8601 UTC；ID 为字符串；金额为最小货币单位整数。

## 列表

小数据列表可使用 `page`/`pageSize`；持续增长或高频翻页数据优先游标：

```json
{
  "data": [],
  "page": {"nextCursor": "...", "hasMore": true},
  "requestId": "req_xxx"
}
```

## 兼容性

- 新增可选字段通常兼容；改变类型、语义、必填性、枚举或错误行为属于潜在破坏。
- 客户端必须容忍未知响应字段，但不得静默容忍关键字段缺失。
- 废弃字段先标记、监测使用、提供迁移窗口，再在新主版本删除。

## 文档

当前 Swagger 位于本地 `/v1/docs`。后续 Change 的 `contracts/openapi.yaml` 与运行时 OpenAPI 必须差异检查。
