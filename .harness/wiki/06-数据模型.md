# 数据模型

## 当前持久化

MySQL schema 由 `apps/api/prisma/schema.prisma` 与 Prisma migrations 管理。

| 模型 | 表 | 责任 |
|---|---|---|
| City | cities | 城市开通与场景 |
| Discovery | discoveries | 路线/钓点详情、状态、排序和指标 |
| FuelPrice/FuelStation | fuel_prices/fuel_stations | 油价与站点 |
| User/Favorite | users/favorites | 用户资料与收藏关系 |
| Ranking | rankings | 榜单配置 |
| Feed | feeds | UGC 与审核状态 |
| ReportTask/DailyMetric | report_tasks/daily_metrics | 报表和日指标 |
| AuditLog | audit_logs | 管理操作前后值 |

## 已知数据风险

- 距离、油价等使用 Float；业务精度、单位与舍入需要在对应 Change 重新确认。
- 当前 User/管理写入缺少正式认证主体，AuditLog actor 可信度需设计。
- ORM 已决定保留 Prisma 7；任何 schema 变化仍需垂直 Change、Prisma Migration 和数据兼容计划。

## 通用字段

参考表可包含：

- `id`：业务 ID，API 层输出字符串。
- `created_at`、`updated_at`：UTC 时间。
- `version`：需要乐观锁的聚合版本。
- `deleted_at`：仅在业务确需软删除时使用。

不得无差别给所有表添加软删除；唯一约束、数据保留和查询复杂度必须评估。

## 关系与状态

- Discovery 受 City 约束，并关联 Favorite、Feed 和 AuditLog。
- City 删除受限；User 城市和 Ranking 城市允许置空。
- 用户/Feed/榜单/路线状态枚举的允许转换尚未形成正式状态机契约。

## 消息

当前无 Outbox、消费记录或 RabbitMQ 表。只有在批准的异步用例中才新增。
