# 可观测性模型

## 日志

当前仅有 request-id/traceId 响应关联和 Nest 默认日志；尚未确认 JSON 结构化日志、脱敏、集中采集或保留策略。

## 目标指标

- HTTP RED：Rate、Errors、Duration。
- 资源 USE：Utilization、Saturation、Errors。
- 业务：路线/钓点列表成功率、详情打开、收藏、油价新鲜度、审核和报表任务。
- MySQL：连接池、慢查询、锁等待、死锁、复制延迟。
- Redis/RabbitMQ 指标仅在对应基础设施批准接入后启用。

## Trace

当前未接入 OpenTelemetry。目标为入口验证/创建 trace，上下游传播，使用稳定低基数字段，禁止请求体、Token 或高敏数据。

每个 Change 必须声明新增/变化的业务指标、告警、Dashboard 和发布观察项。
