# 系统上下文

出门溜溜是户外自驾路线、钓点和加油服务发现产品，包含移动端与运营后台。当前仅有本地开发拓扑。

```text
Mobile User -> apps/mobile (H5 / WeChat build)
              -> /v1 HTTP
Operator    -> apps/admin
              -> /v1/admin HTTP
                 -> apps/api (NestJS)
                    -> Prisma
                       -> MySQL 8.4 Docker
```

## 信任边界

- 客户端与 Admin 浏览器均不可信；当前写 API 尚无已确认认证授权，是发布阻塞项。
- API 中间件接收或生成 x-request-id，但尚无生产 Ingress 信任边界。
- 当前数据库仅为 Docker 本地环境；生产网络、账号、TLS 和备份尚未设计。
- 定位/导航使用客户端宿主能力；油价、站点、内容安全等真实外部来源尚未确定。

目标端、外部供应商、数据分类、地域、SLO 和合规仍由当前 Change 澄清。
