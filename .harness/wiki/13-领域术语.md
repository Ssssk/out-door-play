# 领域术语

| 术语 | 定义 |
|---|---|
| Change | 一次可独立评审、实现、验证和归档的系统变化 |
| Gate | 进入下一阶段前必须满足且有证据的门禁 |
| Rule | 长期、强制或默认遵守的工程约束 |
| Wiki | 当前系统已经成立的事实，不是未来计划 |
| Skill | AI/人工执行某类任务的可复用过程 |
| Acceptance Criterion | 可独立验证需求是否满足的验收条件 |
| Traceability | 从需求到设计、任务、测试和证据的可追踪关系 |
| Outbox | 与业务事务同库写入、随后可靠发布消息的模式 |
| Idempotency | 同一请求或消息重复执行不产生额外业务副作用 |
| DLQ | 达到重试上限或永久失败消息进入的死信队列 |
| Fresh-context Review | 不继承实现对话、且无写权限的独立验收 |
