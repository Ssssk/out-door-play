# 可访问性验证

## 适用平台与标准

- 微信小程序（主目标端）：验证 `SceneTabs.vue` 的 `role="tablist"` / `role="tab"` / `aria-label` / `aria-selected`，以及胶囊吸顶在状态栏与胶囊区下的可见性。
- 运营管理后台 Web（Chrome）：验证新增配置页的表格输入、开关、保存与二次确认弹窗的键盘可达性与可见焦点。
- H5：仅验证语义属性不丢失、构建通过，不作为主验收端。
- 参照 `AGENTS.md` §7 与 `NFR-A11Y-001`；不引入新的可访问性框架。

## 字号、对比度和触控区域

- 胶囊保持 28rpx 字号、70rpx 最小高度、999rpx 圆角；active 态 `var(--chumen-ink)` 背景 + `var(--chumen-lime)` 文字 + `font-weight: 800`，不只靠颜色区分状态。
- 分类数量从 1 变 2 时不缩小触控区域、不压缩间距；`white-space: nowrap` 保持标签完整可读。
- 后台表格沿用 Element Plus 默认字号与对比度；错误提示使用组件既有语义色，不自定义低对比度文本。

## 键盘、焦点与语义

- 小程序胶囊使用原生 `button`，保留 `role` 与 `aria-selected`；配置化后每个启用项都有稳定的 `:key="tab.scene"`。
- 后台：`el-input` / `el-input-number` / `el-switch` / `el-button` 均可 Tab 到达并有可见焦点环；`ElMessageBox` 二次确认可键盘关闭；保存中禁用态有明确视觉反馈。
- 只读账号视图下禁用控件仍可读，不被 `aria-hidden` 隐藏关键信息。

## 动效、屏幕阅读与错误提示

- 本 Change 不新增动效；配置切换不引入闪烁（缓存/默认值立即渲染）。
- 错误提示通过 `ElMessage` 与表单内联文案呈现，文案与具体输入项对应；不使用仅靠颜色或纯图标传达错误。
- 配置失败在小程序端静默回退，不弹阻断弹窗；不产生重复朗读或焦点跳转。
