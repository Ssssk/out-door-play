# 验收标准

所有 AC 使用 `GIVEN / WHEN / THEN / AND` 描述外部可观察结果；测试人员在不知道实现细节的情况下也能判定通过或失败。

## AC-CFG-001 默认配置不改变 C 端可见内容

- **关联需求**：FR-CFG-001、FR-CFG-007、NFR-COMPAT-001
- **GIVEN** 系统尚未写入 `scene_tabs` 配置记录，且运行的是本 Change 上线后的 API 与小程序包
- **WHEN** 用户冷启动进入首页
- **THEN** 首页只显示 1 个分类胶囊「粗门溜车」，不显示钓鱼分类
- **AND** 首页路线列表正常加载，吸顶分类条不出现空白或塌陷
- **验证方式**：微信小程序目标端人工 + 组件测试

## AC-CFG-002 后台保存名称、排序与启停后生效

- **关联需求**：FR-CFG-002、FR-CFG-004
- **GIVEN** 运营以具备 `config:write` 的账号打开「系统配置 / 首页分类目录」
- **WHEN** 将 `drive` 名称改为「周末溜车」、开启 `fish` 并将其 `sort` 调到 `drive` 之前，点击保存并看到成功提示
- **THEN** 用户下次进入首页（`onShow` 触发配置拉取）看到两个胶囊，顺序为钓鱼在前、溜车在后，名称与后台一致
- **AND** 未重新构建、未重新上传小程序代码包
- **验证方式**：后台 E2E + 小程序目标端人工

## AC-CFG-003 隐藏分类在发现列表被服务端拒绝

- **关联需求**：FR-CFG-003、NFR-SEC-001
- **GIVEN** `fish` 配置为隐藏，数据库中存在 `scene = fish` 且 `status = online` 的路线数据
- **WHEN** 直接调用 `GET /v1/routes?city=450100&scene=fish&limit=10`（绕过客户端 tab）
- **THEN** 返回 200 且数据为空数组，不返回任何 `fish` 卡片
- **AND** `GET /v1/routes?scene=drive` 仍正常返回溜车数据
- **验证方式**：API 集成测试 + 契约测试

## AC-CFG-004 隐藏分类在收藏列表被服务端拒绝

- **关联需求**：FR-CFG-003、FR-CFG-009
- **GIVEN** 登录用户已收藏 `fish` 场景内容，且 `fish` 被配置为隐藏
- **WHEN** 调用 `GET /v1/user/favorites?scene=fish`
- **THEN** 返回 200 且数据为空数组
- **AND** 收藏数据本身未被删除，取消隐藏后再次查询可原样返回
- **验证方式**：API 集成测试（真实 MySQL）

## AC-CFG-005 留详情与分享直达

- **关联需求**：FR-CFG-005、NFR-COMPAT-001
- **GIVEN** `fish` 被隐藏，且存在一条已分享的钓点详情链接
- **WHEN** 用户从聊天中打开该链接，或直接调用 `GET /v1/spots/:id` / `GET /v1/routes/:id`
- **THEN** 详情页正常渲染并返回 200，不出现「分类已下线」阻断
- **AND** 详情页分享出去的新链接仍可打开，本地兜底数据仍可用
- **验证方式**：小程序目标端人工 + API 集成测试

## AC-CFG-006 隐藏场景不被预取或缓存复活

- **关联需求**：FR-CFG-009、FR-CFG-008
- **GIVEN** 用户曾以 `fish` 启用状态使用过首页，`listCache` 中存在 `fish` 列表缓存
- **WHEN** 运营把 `fish` 改为隐藏，用户再次进入首页并下拉刷新
- **THEN** 首页不出现 `fish` 分类，也不展示任何 `fish` 卡片
- **AND** 网络请求中不存在对隐藏场景的预取调用，旧版本缓存 key 不再命中
- **验证方式**：组件测试 + 目标端抓包/日志人工核对

## AC-CFG-007 收藏页同步与选中态校正

- **关联需求**：FR-CFG-009、FR-CFG-008
- **GIVEN** 用户当前在收藏页选中了 `fish`，随后 `fish` 被配置为隐藏
- **WHEN** 用户切走再回到收藏页触发 `onShow`
- **THEN** 收藏页只显示启用分类，选中态自动回退到首个启用项并加载对应列表
- **AND** 不出现「选中项不可见」或空列表无提示的状态
- **验证方式**：组件测试 + 目标端人工

## AC-CFG-008 场景白名单阻止后台造场景

- **关联需求**：FR-CFG-006、NFR-SEC-001
- **GIVEN** 运营具备 `config:write`
- **WHEN** 提交包含 `scene = camping` 的配置，或提交含未知字段/非整数 `sort`/超长 `label` 的配置
- **THEN** 返回 422 且错误码为 `CONFIG_INVALID` 或 `COMMON_VALIDATION_FAILED`，配置记录不发生变化
- **AND** 前端逐项展示中文校验提示，不展示内部异常堆栈
- **验证方式**：API 集成测试 + 后台 E2E

## AC-CFG-009 至少保留一个启用分类

- **关联需求**：FR-CFG-007
- **GIVEN** 当前配置中只有一个启用分类
- **WHEN** 运营关闭最后一个启用项并保存
- **THEN** 返回 422，提示「至少保留一个启用分类」，原配置保持不变
- **AND** 若数据库已有损坏配置（0 个启用项），公开读取接口仍返回内置默认（仅 `drive` 启用）
- **验证方式**：API 集成测试 + 单元/组件测试

## AC-CFG-010 损坏或非法配置读取兜底

- **关联需求**：FR-CFG-007、FR-CFG-008、NFR-RELI-001
- **GIVEN** `system_configs` 中 `scene_tabs` 的 JSON 缺少字段、含未知 `scene`、类型错误或 `revision` 非整数
- **WHEN** 调用公开配置接口并进入首页
- **THEN** 返回内置默认配置，首页正常渲染且只显示「粗门溜车」
- **AND** 日志记录一次配置校验失败事件，不抛出未处理异常、不返回 500
- **验证方式**：单元测试 + API 集成测试

## AC-CFG-011 配置接口不可用时回退

- **关联需求**：FR-CFG-008、DEC-009、NFR-RELI-001
- **GIVEN** 配置接口返回 404（老服务端）、5xx 或超时，或设备处于弱网
- **WHEN** 用户进入首页或收藏页
- **THEN** 使用上次成功配置；无上次成功值时使用内置默认，首屏正常渲染
- **AND** 不弹出阻断性错误弹窗，不阻塞路线列表请求，不出现重复并发请求
- **验证方式**：故障注入组件测试 + 目标端弱网人工

## AC-CFG-012 权限分级

- **关联需求**：FR-CFG-011、FR-CFG-002、NFR-SEC-001
- **GIVEN** 账号 A 只有 `config:read`，账号 B 有 `config:write`
- **WHEN** A 打开页面并尝试直接调用 `PUT /v1/admin/config/scene-tabs`
- **THEN** A 可查看但页面无保存/重置/编辑能力，直接调用返回 403；B 可正常保存
- **AND** 服务端 Guard 独立授权，不依赖前端按钮隐藏
- **验证方式**：API 集成测试 + 后台 E2E

## AC-CFG-013 并发保存冲突

- **关联需求**：FR-CFG-011、DEC-007
- **GIVEN** 两名运营同时以 `revision = 3` 打开配置页
- **WHEN** 两人先后提交不同配置
- **THEN** 第一次保存成功并得到 `revision = 4`，第二次返回 409 `CONFIG_VERSION_CONFLICT`
- **AND** 前端提示「配置已被其他运营更新，请刷新后重试」并自动重新拉取，不静默覆盖前者
- **验证方式**：API 集成测试（并发）+ 后台 E2E

## AC-CFG-014 重复提交

- **关联需求**：FR-CFG-011、FR-CFG-002
- **GIVEN** 运营在保存请求进行中
- **WHEN** 连续快速点击保存按钮 3 次
- **THEN** 只发出一次有效写入，`revision` 只增加 1，无重复配置记录
- **AND** 保存中按钮禁用，失败后按钮恢复可用且表单内容不丢失
- **验证方式**：后台 E2E + API 集成测试

## AC-CFG-015 后台误导文案修正

- **关联需求**：FR-CFG-010、DEC-003
- **GIVEN** 运营打开「城市管理」页并展开场景编辑
- **WHEN** 查看页面说明与场景字段提示
- **THEN** 文案说明「城市场景标记仅用于资料维护，不影响小程序端显隐」，并指向「系统配置 / 首页分类目录」
- **AND** 修改 `City.scenes` 后小程序首页分类与列表可见性不发生变化（行为保持不变）
- **验证方式**：后台人工核对 + 回归测试

## AC-CFG-016 滚动发布四种组合兼容

- **关联需求**：NFR-COMPAT-001、FR-CFG-005、FR-CFG-008
- **GIVEN** 默认配置（`drive` 启用、`fish` 隐藏）且未做任何运营改动
- **WHEN** 分别在「旧包+旧服」「旧包+新服」「新包+旧服」「新包+新服」下进入首页并打开一条详情
- **THEN** 四种组合首页均只显示「粗门溜车」，详情均可打开
- **AND** 「新包+旧服」在配置接口 404 时按 `AC-CFG-011` 回退，无异常日志刷屏
- **验证方式**：目标端人工矩阵 + E2E

## AC-CFG-017 契约登记与校验

- **关联需求**：FR-CFG-001、FR-CFG-002、DEC-011
- **GIVEN** 实现完成后的 API 代码与本 Change 的 `contracts/openapi.yaml`
- **WHEN** 在 `apps/api` 执行 `pnpm test:contract`
- **THEN** 命令退出码 0，输出显示校验了本 Change 的 3 个 operation（`getPublicSceneTabs`、`getAdminSceneTabs`、`updateAdminSceneTabs`）
- **AND** 故意移除 `contractPaths` 中本 Change 条目时，测试不再覆盖这 3 个 operation（用于证明登记有效）
- **验证方式**：契约测试 + 命令输出证据

## AC-CFG-018 目标端与可访问性

- **关联需求**：NFR-A11Y-001、FR-CFG-001、FR-CFG-002
- **GIVEN** 微信小程序体验版与后台 Chrome 环境
- **WHEN** 检查分类胶囊语义属性、选中态、触控区域，以及后台表格的键盘操作与可见焦点
- **THEN** 胶囊保留 `role="tablist"` / `role="tab"` / `aria-selected`，触控高度不低于 70rpx；后台输入与开关可键盘操作
- **AND** 真机/体验版截图与检查记录进入 `evidence/`，H5 构建不因本 Change 失败
- **验证方式**：目标端真机人工 + 组件测试 + 可访问性检查记录

## AC-CFG-019 性能、日志与审计

- **关联需求**：NFR-PERF-001、NFR-OBS-001、FR-CFG-011
- **GIVEN** 容器化 MySQL、20 RPS 持续 5 分钟的公开配置读压测，以及一次管理端成功保存
- **WHEN** 采集服务端耗时与日志
- **THEN** P95 ≤ 200ms、P99 ≤ 500ms、错误率 < 0.1%；日志可按事件名检索到配置读取失败、校验失败、并发冲突与隐藏场景拒绝四类事件
- **AND** 管理端写入日志含操作者与 ISO 8601 UTC 时间，日志不含 Secret 与非必要的用户输入原文
- **验证方式**：性能测试报告 + 日志断言测试 + 安全评审记录
