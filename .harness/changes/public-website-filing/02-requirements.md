# 需求规格

## 用户与场景

官网访客需要快速理解“个人生活感悟记录”站点的内容范围；备案审核人员需要在首页底部找到备案号位置并核对信息。

## 功能需求

### FR-WEB-001 静态官网首屏与产品介绍

- 描述：提供响应式的一页式个人内容站，展示文章/随笔、知识整理、图片和日志四类内容。
- 来源 ID/锚点：SRC-USER-20260912-001 / “服务名称是个人生活感悟记录…个人知识整理、图片、文章、日志记录”；当前对话 2026-09-12。
- 业务规则：页面内容必须是静态可读文本；不依赖 API、登录或第三方脚本。
- 权限：公开访问。
- 数据口径：页面是个人站点说明，不把示例文案当作实时业务数据或平台统计。
- 失败行为：静态服务器无法加载时由部署环境负责返回入口，不引入客户端重试或假数据请求。

### FR-WEB-002 备案信息展示与链接

- 描述：首页页脚仅保留一个备案号位置，当前展示用户提供的 ICP 备案号。
- 来源 ID/锚点：SRC-SCREENSHOT-20260912-001 / 附件三项提示；`turn0search0` / 工信部备案展示要求；`turn0search1` / 公安备案平台图标与编号代码。
- 业务规则：展示用户提供的真实 ICP 备案号 `鄂ICP备2023015599号-4`，不得伪造其他编号；不在主导航或正文区域新增备案导航；取得公安编号后再补充官方代码。
- 权限：公开访问。
- 数据口径：编号以主管部门当前审核结果为准。
- 失败行为：公安备案号未取得时不显示虚构编号，页脚仅展示已提供的 ICP 备案号。

### FR-WEB-003 官网域名解析

- 描述：在腾讯云 DNSPod 的 `chumenliuliu.cloud` 解析区为官网主机名 `www` 配置指向现有官网服务器的 A 记录。
- 来源 ID/锚点：SRC-USER-20260912-003 / “腾讯云已在内置浏览器中登录，请配置域名解析”；DNSPod 当前 `@ A 124.223.220.242` 记录。
- 业务规则：新增 `www A 124.223.220.242`，TTL 使用 DNSPod 表单默认的 600 秒；保留现有 `@ A 124.223.220.242`，不猜测其他目标地址。
- 权限：腾讯云 DNSPod 域名管理员。
- 数据口径：DNSPod 控制台保存成功是配置证据；公网递归 DNS 的最终刷新受运营商缓存影响。
- 失败行为：若保存失败或目标地址不明确，停止后续解析修改并保留当前记录。

### FR-WEB-004 域名入口与管理后台路由

- 描述：生产 Web 镜像同时提供官网静态首页、`/admin/` 管理后台和 `/v1/` API 反向代理，Nginx 响应 `www.chumenliuliu.cloud` 与根域名。
- 来源 ID/锚点：SRC-USER-20260912-004 / “对应远程服务器nginx配置…检查下还有哪里要修改的都一起改掉”；SRC-CODE-001 / 现有 Docker/Nginx 结构。
- 业务规则：官网根路径使用 `website/dist`；后台构建基路径和 Vue Router history base 均为 `/admin/`；`/admin` 重定向到 `/admin/`；不得覆盖 `/v1/` API 代理。
- 失败行为：Nginx 或容器构建检查失败时，不宣称远程已发布；保留可回滚的旧镜像/配置。

### FR-WEB-005 小程序生产 API 地址

- 描述：小程序生产构建统一请求 `https://www.chumenliuliu.cloud/v1`。
- 来源 ID/锚点：SRC-USER-20260912-004 / “小程序的访问地址都要调整”；现有 `apps/mobile/.env.production` 与体验版工作流。
- 业务规则：开发环境继续使用本地/测试 API；生产环境和体验版 CI 不再使用示例域名或公网 IP；微信公众平台 request 合法域名需由管理员同步配置。
- 失败行为：域名 HTTPS 或 `/v1/` 代理未可用时，小程序构建仍可生成但不得宣称真机请求已通过。

## 非功能需求

### NFR-WEB-001 静态兼容与可访问性

页面在桌面和 320px 以上窄屏可读，无横向滚动；交互控件有键盘焦点、语义标签和可感知文本；入口无外部运行时依赖。

## 非目标

- 代替用户提交真实 ICP 或公安联网备案。
- 修改后端业务 API、数据库、Redis、消息系统和公安备案资料。
- 用户已授权域名、远程 Nginx 调整和 SSL 服务角色授权；已核实 SSH 用户、现有容器、备份路径和证书方案并完成远程 Web 部署。微信 request 合法域名和公安备案仍属于平台侧后续动作。
