# 技术设计

## 目标与非目标

目标是提供一个无需构建即可部署的个人生活记录站，并在首页底部保留单个备案展示位；生产 Web 镜像同时把管理后台挂载到 `/admin/`，API 保持 `/v1/` 反向代理，小程序生产构建指向同域 HTTPS API。当前展示用户提供的 ICP 备案号；公安联网备案信息待平台审核后补充。远程服务器写入和 TLS 已按用户授权完成，微信 request 合法域名仍由小程序管理员执行。

## 当前流程

现有仓库主要提供 uni-app 移动端、Vue 管理端和 NestJS API，没有单独的网站静态根目录。

## 目标架构与数据流

```text
DNSPod `www` -> 124.223.220.242 -> TLS 终止层 -> Nginx 容器
                                             ├─ `/` -> website/dist/index.html
                                             ├─ `/admin/` -> apps/admin/dist
                                             └─ `/v1/` -> api:3100
```

不请求 API，不读取浏览器存储，不保存个人信息。

## 前端设计

- 页面：单路由首页，锚点导航到最近记录和关于本站；ICP 备案号只出现在页脚。
- 组件：语义 HTML 区块、备案卡片、页脚；自包含样式和脚本。
- 交互：移动端导航按钮、平滑锚点、键盘焦点和减少动态效果支持。
- 跨端兼容：桌面 Chrome/Edge 以及常见移动浏览器；静态文件无平台专属 API。

## 安全与隐私

页面不包含 Secret、第三方追踪脚本、用户输入或外部写接口。ICP 备案编号使用用户提供的真实值；公安编号必须由主管部门平台生成后再补充，不能猜测。

## UI/UX、文案、目标端与可访问性

使用简洁的深色与荧光黄视觉 token，首屏直接说明个人记录站的内容范围；文案覆盖知识、图片、文章和日志，不与出门溜溜产品绑定。提供跳过链接、语义导航、按钮 `aria-expanded`、可见焦点和窄屏布局。

## 应用 CI、供应链、SBOM 与制品

新增目录零第三方依赖；验证入口文件、同目录资源引用、脚本语法和 Git diff。全仓质量命令按现有 Change 基线执行，不把该静态入口误报为 API/数据库验证。

## 发布、迁移和回滚

生产 Web 镜像将 `website/dist` 复制为静态根目录、将管理端复制到 `/admin/`，并由 Nginx 负责 API 代理和 HTTPS。证书通过 Certbot webroot 续期，deploy hook 复制到 `/opt/chumen/certs` 并 reload 容器；回滚使用备份的 Compose 配置、Nginx 配置和上一个 Web 镜像。域名 DNS 已在 DNSPod 保存，微信 request 合法域名和公安备案仍由发布负责人在外部平台完成。

## 备选方案与决策

| 方案 | 优点 | 缺点 | 风险 | 结论 |
|---|---|---|---|---|
| 自包含静态 HTML | 零依赖、易交给接入商部署 | 动态能力有限 | 低 | 采用 |
| 复用 uni-app H5 | 复用业务代码 | 需要构建和运行时，备案页不独立 | 中 | 不采用 |
| 新建全栈官网 | 可扩展 | 超出备案展示需求并引入运维 | 中高 | 不采用 |
