# UI/UX 评审

视觉方向：保留易读的深色底与荧光黄点缀，但品牌改为“个人生活感悟记录”，使用大字号首屏和四类内容卡片，首屏直接说明站点用途。

检查项：

- 语义 HTML、跳过链接、主导航和按钮 `aria-expanded` 已实现。
- 链接、按钮和移动导航具备可见键盘焦点。
- 320px 以上窄屏改为单列，不依赖横向滚动。
- 正文保持可读字号，使用 `prefers-reduced-motion` 降低动效。
- 页面只在页脚展示一个用户提供的 ICP 备案号 `鄂ICP备2023015599号-4`，不在导航和正文重复出现；公安联网备案信息待平台审核后补充。

结论：针对静态官网的 UI/UX 风险可接受；真实备案图标替换后需由产品 Owner 做一次上线前检查。
