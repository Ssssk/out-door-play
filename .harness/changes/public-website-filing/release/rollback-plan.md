# 回滚计划

静态站点回滚到上一个已验证的 `website/dist` 版本即可，不涉及数据库、API、缓存或消息迁移。若备案号码替换错误，先恢复上一版页面并暂停域名发布，再由 Owner 核对主管部门发放的真实编号。

域名接入同时改变 Web 镜像目录和后台基路径，回滚必须整体恢复前一 Web 镜像与配套 Nginx 配置，不可单独恢复 HTML。远程操作前记录当前镜像 digest、端口、TLS 配置和环境变量引用；不读取或回显 Secret。若后台深链、API 健康检查或 TLS 验证失败，恢复原镜像和配置，再验证原入口。此变更不需要数据库迁移。
