## 设计 Token 与可访问性

- 小程序沿用 `--chumen-ink` / `--chumen-lime` / `--chumen-canvas`、70rpx 高度、999rpx 圆角、28rpx 字号；active 态不只靠颜色（含 `font-weight: 800`）。
- 后台沿用 Element Plus，不新增色值、字体或间距 Token。
- 3 个 tab 与二级筛选保留 `role="tablist"` / `role="tab"` / `aria-selected`；后台输入与按钮可键盘操作并有可见焦点。
- 多分类横向排列保留 `white-space: nowrap` 与 flex 容器；一期 3 项不引入横向滚动交互。

## 设计偏差

- 偏差 1：「粗门洗车」与「露营/打卡」一期无数据，接受空态引导（Q-E01 已于 2026-11-08 由用户裁决接受空态、不预置数据，待需求 Gate 书面确认）。
- 偏差 2：小程序不做子类型第三层 tab，仅以卡片标签与列表参数承载（DEC-E08，需产品确认）。
- 偏差 3：不新增洗车独立详情页，复用 `route-detail`（DEC-E07）。
- 以上偏差需产品与 UX Owner 在需求/设计 Gate 明确接受。
