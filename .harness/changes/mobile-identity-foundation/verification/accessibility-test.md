# 可访问性验证

## 适用平台与标准

- H5：键盘、焦点、语义、对比度和缩放；微信小程序：可用标签、字号、触控、屏幕阅读能力按真机支持验证。

## 字号、对比度和触控区域

- 登录、保存、收藏、退出的触控区域和文字对比度使用现有 token 检查；错误不得只以红色表达。

## 键盘、焦点与语义

- H5 Tab 顺序、输入焦点、提交后错误焦点/说明；微信软键盘不遮挡昵称/登录控件。

## 动效、屏幕阅读与错误提示

- loading 有文本语义；会话过期和字段错误可理解；不依赖无限动画或自动消失 Toast 作为唯一信息。

## 测试矩阵与证据
