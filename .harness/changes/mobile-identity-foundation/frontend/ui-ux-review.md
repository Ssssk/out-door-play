- 来源：已批准 v1.1.0 mine/edit/favorite/route-detail 需求、现有 2026-09-01 页面实现和本 Change AC。

## Wot Design Uni 与设计 Token

- 使用现有 `--chumen-*` token；登录表单/按钮优先 Wot 组件，不复制基础输入和 loading。
- destructive logout 需要确认或清晰后果；收藏不需要二次确认但需 pending 防重复。

## 文案、反馈与破坏性操作

- “登录已过期，请重新登录”“微信服务暂时不可用，请稍后重试”“保存失败，请检查网络后重试”。
- H5 dev 明示“仅本地开发账号”；生产不出现该入口。
- 未知内部错误只显示安全通用文案和可复制 requestId，不展示平台/数据库 message。

## 安全区、键盘、横竖屏与设备尺寸

- 登录/编辑验证底部安全区、软键盘遮挡、320px 窄屏和长错误文案；保持现有 max-width shell。
- 登录回跳只允许内部页面白名单，拒绝任意 URL。

## 可访问性设计

- 关键按钮可读文本、足够触控区域；pending 同时用 loading/disabled/文本，错误不只用颜色。
- 昵称输入关联错误文本；H5 检查键盘/焦点；微信检查可访问性标签支持情况。

## 设计偏差与批准

- 无独立登录视觉稿：使用现有品牌/组件系统作为候选，需 UI/UX Owner 签署。
- 微信隐私授权文案依赖正式小程序配置，当前 pending。
